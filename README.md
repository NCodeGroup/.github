# .github

NCodeGroup's organization profile, default community files and workflow templates. GitHub uses each default in every
NCodeGroup repository that has none of its own; a repository's own file, or its own `.github/ISSUE_TEMPLATE/` folder,
takes precedence.

| Default | Files |
| --- | --- |
| Organization profile | [profile/README.md](profile/README.md) |
| Security policy | [SECURITY.md](SECURITY.md) |
| Contributing guide | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Code of conduct | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Governance | [GOVERNANCE.md](GOVERNANCE.md) |
| Issue forms | [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/): Epic, Feature, Bug and Task, each setting its issue type and asking for the sections the project template's Definition of Ready needs ([ADR-0042](docs/decisions/project-template/0042-work-is-planned-as-epics-stories-and-plan-steps-on-a-kanban-flow.md)); blank issues stay available |
| Workflow templates | [workflow-templates/](workflow-templates/README.md): NCode code review |
